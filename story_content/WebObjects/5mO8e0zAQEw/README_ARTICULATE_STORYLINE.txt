PETAZA Misi 3 — Tekanan Zat Gas
Paket Web Object untuk Articulate Storyline

PERBAIKAN UTAMA
- Bug Tahap 5 → Tahap 6 diperbaiki. Tombol transisi sekarang memakai fungsi goToApply() dan tahap 6 dirender dengan struktur soal yang benar.
- Tahap AMATI memakai gambar fenomena kontekstual besar: Peta dan Zaza mengamati balon, pompa sepeda, dan bola.
- Tahap TERAPKAN menggunakan judul “MENYELESAIKAN MASALAH DENGAN KONSEP INI”.
- Setelah semua soal benar, muncul tombol “DAPATKAN LENCANA PENJELAJAH”.
- Setelah lencana diklaim, muncul hasil akhir “SELAMAT, PENJELAJAH! — TEKANAN ZAT GAS” dan status “MISI 3 SELESAI”.
- Peta dan Zaza tampil sebagai tokoh pendamping pada dialog.

PENGGUNAAN DI ARTICULATE STORYLINE
1. Ekstrak ZIP ke satu folder.
2. Pertahankan index.html dan folder assets dalam satu lokasi.
3. Di Articulate Storyline pilih Insert > Web Object dan arahkan ke index.html.
4. Jangan memisahkan index.html dari folder assets.
5. Setelah publikasi Storyline, uji Web Object pada output final.
