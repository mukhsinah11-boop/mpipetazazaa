PETAZA Challenge - Paket Web untuk Articulate Storyline

Struktur:
- index.html
- assets/style.css
- assets/app.js
- assets/peta_zaza.png

Cara memasukkan ke Articulate Storyline:
1. Ekstrak folder ini terlebih dahulu.
2. Di Storyline pilih Insert > Web Object.
3. Pilih folder PETAZA_Challenge_Storyline (folder yang berisi index.html).
4. Pastikan index.html berada di level paling atas folder.
5. Jalankan Preview/Publish Storyline.

Catatan:
- Paket ini offline/self-contained dan tidak membutuhkan internet.
- Maskot PETA dan ZAZA dipertahankan.
- Jangan memindahkan index.html tanpa folder assets, karena HTML memanggil CSS, JavaScript, dan gambar dari folder assets.
